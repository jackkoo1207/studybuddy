# 教學劇本（Teaching Playbook）— 主檢索頁

## 摘要
本頁是 agent 每次教學決策的**主入口**。把問卷答案（決策輸入）轉換為具體的「教什麼 / 怎麼教 / 教多少 / 用什麼語氣」。讀完本頁，依需要再深入 [[topics/english-content-by-level]]、[[topics/stage-activities]]、[[concepts/child-personality-archetypes]]。

---

## 第一步：讀取決策輸入
見 [[topics/decision-flow]]。從問卷取得：月齡、六通路分數、E1–E6 環境、EA/EB 能力題、G 目標與螢幕接受度、城市線級 F1、家長補充描述。

## 第二步：定四個坐標
| 坐標 | 來源 | 頁面 |
|---|---|---|
| 英語等級 L0–4 | EA/EB + E1–E6 | [[concepts/english-tutor-levels]] |
| Doman 發育階段 1–7 | 六通路評分 | [[concepts/doman-seven-stage-framework]]、[[concepts/developmental-profile-scoring]] |
| 城市線級 1–5+港 | F1 | [[concepts/city-tier-adaptation]] |
| 性格原型 | 家長描述+評估 | [[concepts/child-personality-archetypes]] |

## 第三步：選內容類型（環境 × 基礎矩陣）
直接引用 [[concepts/english-tutor-levels]] §起點矩陣：env3 強→沉浸對話；env0 零→聲音暴露/親子兒歌。矩陣只定「起點類型」。

## 第四步：定教學法（依等級）
- **L0（0–18m）**：聲音暴露——英文兒歌、節奏律動、媽媽聲音朗讀（**不開數字人對話**）。
- **L1（18–30m）**：實物命名 + TPR 指令 + 簡單繪本（[[concepts/method-tpr]]）。
- **L2（30–42m）**：圖卡配對 + 兒歌跟唱 + 簡單問答。
- **L3（42–54m）**：數字人對話 + Phonics 遊戲 + 主題詞彙（[[concepts/method-phonics]]）。
- **L4（54–72m）**：角色扮演 + 故事複述 + 書寫預備（對標 Cambridge Pre-A1）。

## 第五步：套性格（決定人格與互動）
查 [[concepts/child-personality-archetypes]]：
- 性格 → Avatar 人格（Guide/Companion/Playmate/Host/Captain/Sensory）。
- 性格 × 基礎 → 具體內容風格（如 explorer+L3 = 動起來的問答）。

## 第六步：算分量與守安全
見 [[concepts/dosage-screen-safety]]：每次時長（L0=0, L1=5, L2=8, L3=10, L4=12 min）× 頻次 × 三重夾緊（AAP 上限 × 線級係數 × 螢幕接受度）。家長拒螢幕 → 轉純語音/離線實物。

---

## 速查：按月齡的英語重點
| 月齡 | 英語等級（參考） | 重點 |
|---|---|---|
| 0–18 | L0 | 聲音暴露、兒歌、親子朗讀 |
| 18–30 | L1 | 實物命名、TPR、繪本 |
| 30–42 | L2 | 跟唱、圖卡、兩詞短句 |
| 42–54 | L3 | 數字人對話、Phonics、主題詞 |
| 54–72 | L4 | 角色扮演、故事複述、書寫預備 |

## 速查：城市線級對報告與載體的影響
見 [[concepts/city-tier-adaptation]]：一線引標準/可付費；五線全白話/離線免費；香港中英雙語/K1–K3。

## 安全總則
- 不診斷、不替代專業評估。
- < 3 歲不開數字人對話（L0）。
- 所有螢幕 ≤ AAP 上限，受線級與家長意願夾緊。
- 資訊不足 → 預設 `socializer` + env 中 + 依月齡等級，並標「待補充」。
