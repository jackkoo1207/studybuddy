# 物理發育評分與輸出（Developmental Profile Scoring）

> **類型**: concept
> **建立時間**: 2026-08-19
> **最後更新**: 2026-08-19
> **來源**: [[raw/questionnaires]] §1.7；[[raw/成長階段建議]] §3

## 摘要
BabyStep 的物理評估（第一部分）用 **4 點量表**（0 尚未／1 偶爾／2 經常／3 穩定）對六通路各 7 題打分。本頁定義如何從分數算出「發育階段、薄弱項、優勢項、每日活動清單」，供 agent 產出報告與教學起點。

## 計分邏輯（[[raw/questionnaires]] §1.7）
1. **各通路階段** = 該通路得分最高的「連續階段」（V1–V7 等，取最後一個穩定達標階段）。
2. **整體發育階段** = 六通路階段的**中位數**。
3. **估算發育月齡** = 依各通路得分線性插值估算（對照 [[concepts/doman-seven-stage-framework]] 年齡窗口）。
4. **薄弱項** = 低於生理階段（依月齡）的通路。
5. **優勢項** = 高於生理階段的通路。
6. 系統自動生成：發育階段說明、薄弱項強化建議、優勢項維持活動、每日建議活動清單。

## 題目結構（六通路 × 7 題）
每題對應一個階段（option A–G = 第一至七階段），家長依日常可觀察行為勾選。題號對照見 [[raw/questionnaires]] §1.1–1.6：
- 視覺 V1–V7、聽覺 A1–A7、觸覺 T1–T7、活動 M1–M7、語言 L1–L7、手部 H1–H7。

## 報告輸出如何「區分城市線級」
評分邏輯對所有線級一致，但**對比基準與用字**按 F1（家長城市線級）分化，詳見 [[concepts/city-tier-adaptation]] 與 [[raw/questionnaires]] §1.8：

| 線級 | 報告對比基準 | 措辭基調 |
|---|---|---|
| 一線 | 同線級同齡（北上廣深） | 專業、可對標 WIDA/Cambridge |
| 二線 | 同線級+全國平均 | 白話解釋國際標準 |
| 三線 | 全國平均 | 「正常範圍，多對話」 |
| 四線 | 全國平均（不製造焦慮） | 全白話、零成本 |
| 五線 | 全國平均（口語） | 完全免費/離線 |
| 香港 | EYFS 階段 | 中英夾雜、K1–K3 銜接 |

## 安全欄
- 本評估**不進行臨床診斷**，僅供家庭早期發展參考。
- 若某通路低於年齡過多，建議家長諮詢專業醫療，而非自行加壓。
