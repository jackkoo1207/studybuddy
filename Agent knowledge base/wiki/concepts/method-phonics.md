# 教學法：Phonics 語音意識（Phonological Awareness）

> **類型**: method
> **建立時間**: 2026-08-19
> **最後更新**: 2026-08-19
> **來源**: [[raw/questionnaires]] §2.2（EB5）、§2.3（G1）、§2.4（Level 3/4）

## 摘要
Phonics / 語音意識是「聽辨單字開頭音、拆解字音」的能力，是英語從「聽說」邁向「讀寫預備」的橋樑。對應問卷 EB5「b-b-ball / c-c-cat」、家長目標 G1「語音意識（Phonics）」。

## 適用等級
- **Level 3（42–54m）**：Phonics 遊戲、主題詞彙，開始注意字母形狀（EB4）。
- **Level 4（54–72m）**：基礎書寫預備、簡單故事複述，對標 Cambridge YLE Pre-A1。

## 操作要領
1. **音素覺察遊戲**：誇張念開頭音 "b-b-ball"，讓寶寶模仿節奏。
2. **首音配對**：找出同開頭音的詞（ball / banana；cat / car）。
3. **字母形狀**：配合視覺通路（[[concepts/six-pathways]] V6 認字母），用字母磁鐵/點字卡。
4. **自然拼讀**：CVC 詞（cat / dog / run）先聽後讀。

## 與其他教學法關係
- 先有 **聽力與詞彙**（[[concepts/method-tpr]]、[[concepts/english-tutor-levels]] Level 0–2），Phonics 才有效。
- 與 **早期閱讀**（[[concepts/method-early-reading]]）互補：Phonics 是「解碼」，閱讀是「識字」。
