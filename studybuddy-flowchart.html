逐節點理解 ⇄ 實作對照

流程節點我的理解（這步在幹嘛）目前實作在哪狀態
Questionnaire家長填寫背景 + 四維度評估 + 目標index.html 問卷（出生日期／F1 線級／E1/E3/E4／G1–G3／V/A/R/SP 階梯）✅ 已實作
Assessment算出四維度階段：視覺／聽覺＝發展通路，閱讀／拼寫＝能力階梯physAssessment() + englishLevel()（R/SP 階梯 → L0–L4）✅ 已實作
Weak spot of babies從評估找出薄弱項（視覺／聽覺落後於月齡）＋家長想優先提升的目標S.phys.weak（視覺/聽覺）＋ S.goal（G1）傳入 DeepSeek✅ 已實作
Lesson planner agent依弱點＋目標＋等級，生成個人化 4 週計畫；課後依進度修訂POST /api/generate-plan → DeepSeek（prompt 讀 lesson-planner-agent.md，rule 3 強調弱點與目標）✅ 初始草稿 🔴 課後修訂
4-week lesson每週主題＋每週 N 課（Day 1..N，支柱、活動、目標詞、時長）計畫 JSON {weeks:[{focus, lessons:[{pillar,activity,how,words,goal}]}]}；本地降級版 generateTeachingPlanLocal()✅ 已實作
Tutor agent數字人導師按今天這一課執行：先規劃 LessonPlan 再逐步教ElevenLabs Convai（PROTOCOL_TEXT + buildAgentContext() 注入 lesson_context；tutor-agent.md 為系統提示）✅ 已實作
Practice課堂練習：彈出小測驗、課後作業、針對四維度課堂內已有：常錯複習 3 步 + 昨日複習 2 步 + 今日 10 步 + 總結 1 步🟡 課內練習有，彈出測驗／課後作業沒有
Weekly Progress analytics每週統計進步：哪些維度提升、哪些還需加強只有一次性 buildProgress()（mastered/pillars/next）＋ schedule 完成數；沒有週期性對比🟡 靜態進度，無週 delta
WPA → WS 回饋迴圈「有進步 / 還需加強」回寫到薄弱項，計畫隨之調整—（計畫生成一次後不自動重算；只有手動「重新生成」按鈕）🔴 迴圈斷開
Tutor capabilities說話／聽／白板寫字／顯示圖片說話=TTS ✅ ｜ 聽=麥克風 STT ✅ ｜ 白板=draw_on_whiteboard ✅ ｜ 圖片=僅已知單字自動 Twemoji 🟡（無 agent 可呼叫的「顯示圖片」工具）✅ 3/4 🟡 圖片

要閉合迴圈，缺這四件事

  • 1. 課後練習資料 — Popup Quiz（課後彈出 2–3 題小測，答案寫回）＋ Post Lesson HW（家長可執行的課後任務）
  • 2. Weekly Progress analytics — 每週結束計算四維度進步（本週 vs 上週：測驗正確率、完成課數、mastered 增量），寫入進度記憶
  • 3. 回饋邊 WPA → WS — 進步的維度移出弱點清單；仍落後的維度提升為下一週強化重點
  • 4. 計畫自動修訂 — 每週結束依新弱點清單重新生成（保留已完成進度），取代目前的一次性生成
  • （小項）Tutor 圖片工具 — 讓 agent 能主動呼叫「顯示圖片」而非只有白板文字＋被動 emoji
